# Fittin v1.5.1 · 有氧记录准确性更新

Android 版本号：29。沿用稳定签名，可从 v1.5.0 覆盖安装，不需要卸载。

## 本次改进

- 修复 FIT 导入总时长丢失：运动时间与包含暂停的总时间分别保留。
- 修复 TCX 多圈心率、步频与最高心率汇总，缺少完整数据时明确省略，不用第一圈冒充全程。
- 修复长期静止时自动暂停误判，以及恢复运动后的异常跳点、当前配速和公里分段计时。
- 实时记录和运动回顾显示每段距离、时长、配速；骑行使用速度。
- 运动回顾补充已有的心率、步频、爬升、功率与数据来源，并适配窄屏和现有主题。

## 更新与数据

建议更新前完成同步或备份。无需重新建立计划，旧记录不被悄悄重算，没有新增数据库结构迁移。
Android 在“我的 → 关于 Fittin → 检查更新”下载新版，也可从第一方下载页直接安装新版 APK。
只有 v1.0.5 及更早的旧签名版本需要先备份再迁移；v1.0.6 起可使用同签名覆盖升级。

## 平台与试用边界

- 发布 Android APK/AAB、Web、Windows、macOS、Linux；iOS 提供无签名构建验证包，不是可直接安装的 IPA 或 App Store 版本。
- 在线高德地图保持关闭；GPS、计时和本机路线示意图可用。精确路线默认仅本机。
- Android 60 分钟锁屏户外记录和已知距离对照仍待用户试用验证，不宣称已验证所有机型的后台可靠性。
- Web 仅前台定位；桌面提供查看、导入和手动记录。桌面包没有 Apple 公证或 Windows 商业签名。
- 本版未复制或还原 RQrun 的专有跑力算法，没有新增未经验证的跑力、疲劳或恢复评分。
