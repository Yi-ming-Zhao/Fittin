# Fittin v1.5.4

- 修复 Agent 已保存完整配置却仍要求配置的问题。连接测试改为可选诊断；重复保存相同配置不会清除测试结果，配置读取期间显示加载状态。
- 修复使用过程中反复出现“正在准备训练空间”的问题。启动完成后，训练与同步刷新不再卸载当前页面；切换账号仍保持数据隔离。
- 跑步轨迹直接叠加在高德真实地图上，支持起终点、全程适配、缩放和定位中断分段。请求失败时保留原图与正确的路线位置。

地图默认关闭，登录后同意分享地图中心点即可加载，无需输入 Key。完整轨迹在本机绘制，不发送给地图服务；地图为按需刷新的图片，不是实时导航。Web 的 Agent Key 仍仅保存在当前页面会话内存中。

Android 沿用原签名，可覆盖更新，版本为 1.5.4（32）。提供 Android、Web、Windows、macOS、Linux；iOS 仅交付无签名构建，不等于 App Store 发布。Android 真机长时间锁屏运动及已知距离对照仍需用户试用。
