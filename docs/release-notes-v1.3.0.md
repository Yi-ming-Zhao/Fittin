# Fittin v1.3.0

## 灵活安排训练

- 在当前小周期内可把尚未完成的训练日调整到今天，其余训练日保持顺序顺延；有未完成训练草稿时会安全阻止换日。
- 开始训练后可从动作库替换当前动作。已完成的组不会被改写，草稿、训练记录和后续重量继承都保留真实动作身份。
- 内置动作库扩充常用居家哑铃动作，并按动作模式、器械、主要肌群、次要肌群和标签分类；支持搜索、自定义动作以及 Agent 读取和修改提案。

## 有氧记录与趋势

- 首页原“切换计划”入口改为“记录有氧”，并新增有氧种类库、历史、详情、编辑和删除页面。
- 跑步、步行、骑行、爬坡和其他项目使用各自适合的字段，例如时长、距离、配速、速度、坡度、心率、步频和海拔增益。
- 支持本机导入 GPX、TCX、FIT 和 CSV；导入前展示预览与警告，按文件指纹防止重复，整批保存保持原子性。
- 趋势页可分别查看力量和有氧，并同时使用主题配色、线型／点型和文字说明，避免只靠颜色区分。

## 登录、Agent 与数据安全

- 登录会话使用可轮换刷新凭据自动续期；除非用户主动退出，短时断网、应用重启或访问令牌过期不再要求重新登录。
- Agent 可读取和提交动作库、配色库修改提案；所有写入继续逐次展示完整差异并等待用户确认，内置内容不可被直接改写。
- Agent 运行支持持久化检查点、确认后续跑、账号隔离、并发版本检查、受限训练日志字段和完整身体数据空值恢复。
- 大型计划的模型回传改为有上限的语义摘要，界面和撤销历史仍保留完整差异；DeepSeek `deepseek-v4-flash` 不再因重复搜索或上下文膨胀而中断。

## 外观与移动端布局

- “我的”重组为账号、外观、训练、数据与隐私、Agent 和关于六个二级入口，相近设置不再混在同一长页面。
- 新增石墨兰、墨色藏红、橄榄手稿等克制配色，并保留黑曜黄铜、午夜钴蓝、波尔多绒、白瓷墨和浓缩火星；全应用不使用青绿或青色强调。
- 首页、身体、计划、PR、Agent、动作库、配色库以及深层编辑页统一安全区、页面留白、内容宽度、键盘避让和至少 44 像素触控区。

## 更新说明

- 版本为 `1.3.0+26`。Android 正式包继续使用 Fittin 稳定签名，可直接覆盖安装 v1.2.1，无需卸载。
- 原生和 Web 存储均采用向前兼容的加法迁移；现有账号、计划、周次、训练草稿、训练记录、身体数据、Agent 会话、配色和登录状态会保留。
- API Key 仍只保存在设备安全存储（Web 仅当前会话），不会同步到 Fittin 云端或写入诊断日志。
- iOS 功能随代码交付并由 CI 执行无签名 Release 构建验证；公开发布物仍为 Android 与 Web。
