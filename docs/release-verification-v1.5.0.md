- 试用版在线高德地图关闭；GPS、计时、本机路线示意图可用，无道路导航。
- Android 60 分钟锁屏户外记录和已知距离对照由用户下载后测试，当前不宣称
  已验证所有手机的后台可靠性。Web 仅前台定位，桌面仅查看、导入与手工记录。
- iOS 是无签名设备构建，不是可安装 IPA、TestFlight 或 App Store 发布。
  桌面包没有 Apple 公证或 Windows 商业签名。
- 本机 iOS 官方组件下载由独立监督继续，CI 已完成无签名构建；它不阻挡本次
  发布，也不会被误报为真机运动验收。

六个能力规范共 11 项要求、16 个场景，均已定位到实现及直接覆盖测试。
规范同步保留未修改的既有场景；发布任务仅在最后的公开入口检查后勾选。

| 能力 | 实现与证据 |

| Web 转发 | `agent_relay.go`；首包/空闲期限、逐片 flush、取消、安全目标测试及公开 DeepSeek SSE |
| 计划生命周期与预览 | `plan_library_provider.dart`、本机/Web 事务、`plan_day_detail_screen.dart`；版本冲突、草稿保留、独立新实例、周次处方 |
| 三级编辑 | `plan_editor_screen.dart`、`template_editor_provider.dart`；草稿往返、定位错误、阶段/组字段保留 |
| 真实运动与私有路线 | 运动模型、控制器、平台定位、独立存储、路线同步和 Go 路由；漂移/暂停/缺失区间、恢复、原子导入、所有权和显式删除 |
| 全应用呈现 | 46 页面覆盖清单、共享布局与直接页面测试、八主题真实 Web 抽查；权限/隐私说明保留，装饰文案移除 |
