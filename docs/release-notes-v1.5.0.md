# Fittin v1.5.0 — 持续完成任务，开始真实记录运动

## 本版变化

- Agent 不再因为应用固定的模型轮数、工具次数、累计输出或总运行时间而终止。供应商截断时自动继续；残缺工具参数不会执行，重复无进展时保留状态等待继续。
- 长对话按页保存和显示。阅读旧消息时不再被新输出拉回底部；Markdown 分块显示，错误前的正文保留，没有正文的失败不会生成空白回复框。
- 训练计划支持停止、恢复和重启。停止保留进度及草稿；重启创建独立实例，保留历史记录，并要求明确处理未完成草稿。
- D1/D2 等训练日可查看详细安排与不同周次；计划编辑改为总览、训练日、动作三级，复杂规则按需展开。
- 跑步、步行、骑行、徒步新增定位准备、开始、暂停、继续、计圈、锁定和结束回顾；室内运动支持计时。总时长与运动时长分开记录，缺失距离不填假数据。
- 路线默认仅本机保存，断网不影响本机计时与轨迹记录。导入保留文件实际提供的路线和分段；精确路线导出及私有云端上传、下载、删除分别确认，不进入普通同步或 Agent 提示词。
- 移除重复的装饰性标题和说明，调整手机页面、深层编辑器与设置的层次和间距。

## 试用边界

- **在线高德地图暂未启用**。本版提供 GPS、计时和离线路线示意图；示意图不是在线地图，不提供道路导航。
- **Android 60 分钟锁屏户外记录与已知距离对照尚待用户实测**。自动化测试和模拟轨迹不能证明所有手机的后台记录可靠；系统省电或终止应用可能造成缺失区间，应用不会补造路线。
- Web 只支持前台定位，不能保证锁屏持续记录。桌面提供查看、导入和手动记录，不宣称手机式后台追踪。
- 供应商仍有单次上下文、输出和速率限制；自动续写可能增加模型费用，可以随时停止。

## 平台与升级

目标发布物为稳定签名 Android APK/AAB、Web、Windows、macOS、Linux，以及 iOS 无签名构建。桌面包未经过 Apple 公证或 Windows 商业签名；iOS 无签名包不是可直接安装的 IPA、TestFlight 或 App Store 发布。

更新使用加法存储迁移，不主动登出或重建用户数据库。具体构建、签名、覆盖升级及线上验收结果以本次发布验证记录为准；本文不是这些检查已经完成的声明。
