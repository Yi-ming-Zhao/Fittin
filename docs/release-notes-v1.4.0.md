# Fittin v1.4.0 — 训练由你安排

- 在首页日程中跳过当天训练，或提前小周期内的其他训练日；未完成草稿和过期页面都有保护。
- 新增自由训练：从动作库组合训练，使用同一套卡片/传统记录界面，不改变当前计划进度。
- 历史训练改用完整记录界面编辑，支持修改日期；删除时可选择仅删除记录，或删除并将训练日释放回计划。较早的训练日会进入补练队列，不抹掉后续进度。
- 动作库扩展至 222 个条目，涵盖常见力量举、健美、举重、器械、自重和体能训练；新增握法、单侧、姿势、计量方式、特殊器械及组法等结构字段。自定义动作和 Agent 工具支持这些字段。
- 有氧库补充室内外训练类型，以及针对性的阻力、平均功率字段。
- 全新正面、背面和侧面解剖负荷图，可放大和点选肌群；显示的是训练组贡献，不代表医学检测或恢复程度。
- 哑铃动作显示哑铃重量图，并区分单只重量和合计负重。
- 改善首页、身体页、动作库、自由训练和深层编辑页面的手机布局，补齐新增中文离线字体。

## 下载与平台说明

- Android：稳定签名 APK 可直接覆盖安装；AAB 供分发使用。
- Web：部署到第一方站点，保留上一版本回滚。
- macOS、Windows、Linux：提供桌面应用压缩包；桌面包未经过 Apple 公证或 Windows 商业签名，系统可能显示来源提示。Linux 需要 GTK 3、libsecret 等运行库；Windows 需要 Microsoft Visual C++ 运行库。
- iOS：提供无签名设备构建用于有资质的开发者签名，不是可直接安装的 IPA 或 App Store/TestFlight 发布。公开 iOS 分发仍需要 Apple Developer 签名配置。

更新不会主动登出，不会重建用户数据库。使用多台设备时建议一起更新，以识别新增动作字段。动作库持续扩充，不声称穷尽所有动作变式；记录重量必须遵循动作的单只/总重约定。
