# Fittin v1.5.3 · 免填 Key 在线地图

Android build 31，沿用稳定签名，可覆盖 v1.5.2，不要卸载旧版。

- 在线周边地图改为使用已配置的个人测试 Key，不再显示输入框。
- 登录后点击地图并确认位置分享即可加载；Key 不进入源码、公开安装包或云同步。
- 每次手动刷新只将一个定位点经 Fittin 转发给高德，Fittin 不保存坐标或图片，不发送完整路线。地图默认关闭，加载失败不影响离线定位和计时。
- 后端限制请求参数、配额和并发，不跟随重定向，不泄露上游错误或 Key。

已用公开示例坐标在 241 实测高德转换与 600×360 地图图片。地图仍是手动刷新图片，不是连续导航。Android 60 分钟真机锁屏户外验证仍待试用，系统强制停止及厂商省电可能中断记录。iOS 仅无签名构建，桌面包未商业签名/公证。
