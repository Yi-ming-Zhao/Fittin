# v1.5.0 界面复核记录

状态：候选页面复核完成；公开部署后的首屏检查仍单独执行。

## 覆盖与证据边界

`test/presentation/route_layout_coverage_manifest_test.dart` 登记了 46 个页面类，
每个页面源文件链接到实际构建该页面或经父页面进入它的组件测试。完整本机
测试通过 662 项；这不是“每个页面、主题、状态都有人工截图”的声明。
共享布局验证覆盖 320×568、390×568、390×844、390×926、桌面、大字体与键盘。
Agent、有氧记录等高风险页面另有逐主题、中英文的真实组件检查。

## 本轮发现和修改

| 范围 | 发现 | 处理及验证 |
|---|---|---|
| Agent 流式会话 | Web 滚轮/触控板没有触摸拖动字段，阅读会被继续拉回底部 | 增加用户滚动方向识别；触摸和滚轮回归通过。真实 Web 输出到第 40 段时仍停留第 13 段，点击“最新”才跳转 |
| Agent 长历史 | 历史全部构建、展开早期记录可能移动阅读位置 | 50 条分页显示、稳定中心锚点；120 条历史的精确位置断言通过 |
| 计划详情 | 大段计划说明挡在 D1/D2 前面 | 默认折叠训练说明；100 段说明的 390×844 测试中，训练日仍可直接点击 |
| 计划编辑 | 所有训练日、动作、规则同时展开 | 总览／训练日／动作三级；高级规则与组详情按需展开，返回保留草稿 |
| 通用标题 | 320px 英文有氧库标题被截断 | 标题完整换行；四个手机尺寸回归通过 |
| 首页、计划、趋势、设置、动作与项目库 | 装饰性说明重复，侵占首屏 | 删掉重复副标题，首页空态压缩为一行；相关 53 项组件测试通过 |
| 身体页 | 装饰标题与空态重复、照片数量文案不准确 | 保留数据、记录入口和必要空态；原有 13 项身体页测试通过 |
| 有氧记录 | 控件容易落在短屏下方；定位准备与正式开始混淆 | 底部固定操作、独立定位准备与开始；四尺寸／八主题／双语状态组件检查通过 |
| 本机与云端路线 | 汇总删除后精确路线不易管理；误操作风险 | 隐私页独立路线入口，云端分页清单，上传／下载／删除分别确认；320px 取消不写入的回归通过 |
| 中文离线显示 | 新增定位、路线与计划操作可能缺字 | 子集字体保留旧字符并补充当前代码字形，1,574 个字符；三项字体回归通过 |

保留的说明限于权限用途、云端/本机边界、单位、导入格式、必填规则、冲突和
删除后果。训练计划原文没有删除，而是折叠。没有添加青绿或青色主题。

## 实际浏览器抽查

本地真实 Flutter Web 已抽查八套主题：瓷白墨韵的身体页与流式会话、黑曜黄铜的
首页/计划/训练日、午夜钴蓝的 320×568 有氧库、石墨兰影的 390×926 三级编辑、
波尔多丝绒的中断运动回顾保存、浓缩余烬的 390×568 有氧入口、墨夜藏红的
短屏二级设置、橄榄手稿的 390×844 配色库。中英文均有实际页面检查；大字体、
键盘和完整主题矩阵复用组件测试，不把它们称为真机人工检查。

八主题抽查未发现新的遮挡、溢出或不可点击问题。数据均来自隔离的合成 QA
数据库；中断运动恢复为暂停状态，结束保存后未遗留定位采集。全部 46 个页面
类的可达性与布局证据见覆盖清单；不声称每个弹窗的每个状态都有人工作图。
