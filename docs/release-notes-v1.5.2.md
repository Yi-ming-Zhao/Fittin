# Fittin v1.5.2 · 锁屏运动记录更新

Android 版本号 30，保持原签名，可直接覆盖 v1.5.1，无需卸载。

## 本次改进

- 原生运动切到后台时立即保存；后台定位回调也触发检查点，不依赖页面刷新或界面定时器。
- Android 增加持续运动通知、通知权限申请和后台/电池设置提示，保留定位前台服务及防休眠锁。
- 防误触锁定保留时长、距离、配速和定位状态，仅长按底部专用按钮解锁；点按和长按屏幕其它位置不解锁。
- 增加可选的高德在线周边地图：使用你自己的 Web 服务 Key，启用前确认位置分享，按需更新位置与缩放。地图失败不影响离线记录。

## 地图与隐私

地图默认关闭，公开安装包不包含共享 Key。Key 仅保留在当前应用会话，退出登录或重启后清除，不进入同步或日志。每次加载只向高德发送一个定位点及网络信息，不发送完整路线。请按自己的高德授权和免费配额使用，可能产生供应商费用。

目前提供按需刷新的周边地图图片，不是连续导航或完整在线轨迹地图。真实个人 Key 验证与各设备网络兼容性仍待配置后试用，不把模拟响应当成高德真实加载证据。

## 升级与平台边界

Android 在“我的 → 关于 Fittin → 检查更新”获取新版。建议先同步或备份，保持原安装，不要卸载。

- Android/iOS 可在主动开始运动后继续后台定位；系统强制停止、清理应用或厂商省电限制仍可能中断。保存的运动可恢复，不伪造缺失路线。
- Android 60 分钟真机锁屏户外测试及已知距离对照仍待用户试用；模拟器测试不代表所有机型已验证。
- Web 只支持前台定位，锁屏或切应用会明确中断。桌面支持查看、导入和手动记录。
- 发布 Android、Web、Windows、macOS、Linux；iOS 仅交付无签名构建验证，不是 App Store/可直接安装版本。桌面包未商业签名或公证。
