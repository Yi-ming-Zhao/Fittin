## Context

1.5.3 将 toolCallingVerified 作为 Agent 可用条件，保存无条件清除验证；配置读取期间显示未配置。AppStartupGate 随响应式首页数据重新显示开屏。现有高德转发仅接受中心点，客户端把静态图与路线画成两块。

## Goals / Non-Goals

**Goals:** 完整配置直接使用；相同配置保留诊断；同账号就绪后不再开屏；路线叠图、起终点、断点与范围适配；保留路线本机隐私。

**Non-Goals:** Web Key 持久化、导航、轨迹上传、修改运动采集、购买地图授权。

## Decisions

- 使用条件改为完整配置，兼容测试结果独立保留；无变更保存保留已验证状态，修改 URL/模型/Key 才失效。读取中显示进度，不显示未配置。
- 开屏按当前身份锁存成功；数据刷新不卸载应用子树。身份变化时隔离旧子树并显示普通加载，首次启动才使用开屏文案。首页启动校验只读一次数据快照，不订阅每次训练数据变更。
- 使用本机 WGS84 到 GCJ02 转换和 Web Mercator 投影，与固定 600×360/scale1 地图坐标一致；以路线包围范围计算中心和缩放。只向后端发送中心点，不发送路线。去除服务器中心 A 标记，客户端绘制路线与起终点。
- 轨迹适配与缩放请求的视口在请求发起时冻结，失败保留旧图；新点可按该视口叠加，刷新重新居中。定位中断不能连线。不支持的坐标系不猜测。
- 沿用现有主题与字体，地图路线使用主题主色和对比描边，不引入青绿。

## Risks / Trade-offs

- 本机坐标转换为近似算法 → 使用公开示例坐标与高德转换交叉对照，保留原始 WGS84，不用于导航或距离计算。
- 异步设置重载/账号变化 → 门控加载状态，账号变化废弃旧地图请求，测试覆盖。
- 静态底图不能无限平移 → 提供适配全程及缩放，图像失效时保持离线示意。

## Migration Plan

无需数据库迁移；候选测试、全平台 CI、原签名覆盖升级、后端本地构建及回滚、Web 原子切换，最后发布 latest.json。版本 1.5.4+32。
