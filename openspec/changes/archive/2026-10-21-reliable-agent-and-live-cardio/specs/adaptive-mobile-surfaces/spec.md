## ADDED Requirements

### Requirement: Concise action-led presentation
All routes SHALL prioritize useful data and a primary action, remove decorative explanatory headings/subtitles, preserve essential units and safety notices, and consistently support all semantic themes without cyan/teal additions.

#### Scenario: Open body metrics
- **WHEN** the user opens body metrics
- **THEN** actionable measurements and history replace the decorative composition eyebrow and promotional subtitle

#### Scenario: Deep route audit
- **WHEN** release validation runs
- **THEN** every route, sheet, dialog and empty/error/loading state is accounted for in the audit with phone, keyboard, locale and theme evidence
