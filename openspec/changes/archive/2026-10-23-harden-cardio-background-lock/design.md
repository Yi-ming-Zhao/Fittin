## Context

现有 Geolocator Android 前台服务已持有 PARTIAL_WAKE_LOCK，iOS 已启用 location background mode。控制器不随页面销毁，但检查点主要依赖 Dart 定时器；Android 13 通知权限没有申请。已有专用解锁区域但没有完整内容防误触隔离。

## Goals / Non-Goals

**Goals:** 后台事件驱动保存；切后台及时检查点；前台启动约束；显示平台后台限制；锁定仍可读且仅按钮可解除。

**Non-Goals:** 强制停止后秘密重启、日常定位、无授权内嵌地图、将模拟器测试宣称为户外准确度证明。

## Decisions

- 继续使用现有 Geolocator，保留 Android 原生 LocationManager（不依赖 Google Play）和唤醒锁；不新增第二条定位流或自建重复服务。
- 定时器与位置回调共用按单调时钟限频的检查点，切后台立即保存；暂停/结束/切账号继续关闭定位。前台恢复立即刷新状态，不隐式重启已中断运动。
- 独立 Android 方法通道查询通知、电池节能状态和打开系统设置；开始记录时请求通知。拒绝通知不伪装为定位失败，不强迫用户免除电池优化。
- 锁定内容保持原尺寸、可读且禁止点击/滚动；底部固定专用长按按钮解锁，普通点击和长按数据不解锁。无障碍语义支持长按操作。
- 地图独立于定位。用户澄清为个人研究自用后，提供默认关闭的个人 Web 服务 Key 接入：官方坐标转换与静态周边地图，按需手动刷新，不发送整条路线。Key 仅当前会话内存保存，账号变化清除，不包含在公开安装包。每次启用先说明位置分享和配额；没有实际 Key 时不宣称真实高德加载已验证。

## Risks / Trade-offs

- 厂商省电/用户强制停止仍可杀进程 → 明确设置提示和检查点恢复，不宣称永不丢点。
- iOS 定时器后台调度不确定 → 位置回调也触发持久化。
- 网页锁屏不能可靠采集 → 继续明确前台限定并中断，而非伪装移动端后台能力。

## Migration Plan

无 schema 变更；1.5.2+30，稳定 Android 签名覆盖升级，CI 全平台构建。先验证公开 Web/资产，再原子更新 Android 更新索引；保留上一版可回滚。

## Open Questions

高德真实个人 Key 调用待用户登录控制台或在设备上自行配置；不将模拟响应当成真实地图验收。
