## Context

1.5.2 地图使用用户会话 Key 直连高德。用户提供了 gaode-key.txt，要求无需自行输入。真实坐标转换及静态图请求已用公开示例坐标成功测试，未输出凭证。

## Goals / Non-Goals

**Goals:** 免填 Key、凭证不进入发布包、登录保护、无坐标持久化、保持取消和账号隔离。

**Non-Goals:** 交互式导航、自动上传路线、付费授权购买、修改已有发布标签。

## Decisions

- 用 `POST /v1/maps/area`，严格接受 latitude/longitude/zoom；坐标在请求体而非 URL，关闭缓存。只访问固定高德 HTTPS 坐标转换和静态图地址，禁止重定向、环境代理，15 秒总超时，16 KiB 转换响应及 2 MiB 图片上限。
- Key 使用服务器 `FITTIN_AMAP_WEB_SERVICE_KEY`，不提供获取 Key 的接口。仅登录用户可调用，每分钟全局 30 次/用户 10 次，最多 2 个并发，避免无限消耗配额。
- 客户端复用认证仓库获取/刷新 access token；账号变化或关闭后丢弃返回值。移除个人 Key 会话状态和输入控件，保留启用确认和手动刷新。
- 默认关闭的地图确认文案说明单点经 Fittin 转发至高德，服务器不记录请求体、坐标、Key 或上游错误内容。整条路线仍仅本机。

## Risks / Trade-offs

- 依赖 Fittin 登录和后端可用 → 失败只影响图片，不影响定位和计时。
- 服务器会临时处理单个坐标 → 明确说明并仅在用户点击确认后传输，不持久化。
- 共享个人配额可能被消耗 → 登录、低速率和并发上限；保留更换 Key 的部署能力。

## Migration Plan

先部署后端与受限环境密钥并验证公开示例图片；客户端变更需要新构建，不修改已发布的 1.5.2 资产。回滚使用上一版二进制及 Web 软链接，旧客户端个人 Key 直连仍可用。
