## Context

内置计划通过 JSON 资源及统一种子协调器加载。五天安排必须保持循环稳定，不新增强制第六天。Agent 当前测试使用指定工具选择；解析器忽略 `reasoning_content`，完整 endpoint 也会被重复追加路径。

## Goals / Non-Goals

**Goals:** 保留用户计划、无损补齐既有安装；通过 DeepSeek 协议模拟测试复现与修复连接及后续工具调用。

**Non-Goals:** 不自动更换当前计划，不编造初始重量或递减幅度；不发布版本，不使用其他项目的供应商密钥。

## Decisions

- 采用现有线性循环和固定组数；力竭组使用 AMRAP，组间休息复合动作 120 秒、孤立动作 60 秒。初始负重为 0，由用户确认起始重量。
- 保留全部动作提示和替代动作到双语计划说明；递减组、21 响、单侧次数保留在动作/阶段名称。腹部训练为可选附加说明，不擅自添加第六训练日或每天强制训练。
- 将新计划需要的 38 个中文字形加入现有离线字体子集，保留原有字形，避免离线时名称及动作说明缺字。
- 测试仅暴露 ping 工具并使用 `tool_choice: auto`；仍检查完整且有效的 ping 调用，不能把普通文本、空流或半截工具调用当作成功。
- 为协议事件、请求消息和本机消息增加可选 reasoning 内容。界面不展示；持久化仍仅在原本本机会话库内。发送到 DeepSeek 模型时带该字段，其他供应商请求保持原格式，避免新增非标准字段破坏兼容性。
- 地址规范化接受以 `/chat/completions` 结尾的完整地址并转换为 Base URL；保持 HTTPS、userinfo/query/fragment 等原有安全规则。

## Risks / Trade-offs

- 自动工具选择可能返回文本 → 测试明确提示工具未通过，绝不绕过写入确认。
- 未提供 DeepSeek Key → 使用真实客户端与协议模拟服务验证；如无法取得用户专用于本任务的 Key，不声称真实供应商验证通过。
- 推理内容增加本机大小 → 复用现有响应和会话大小上限，并与其他消息一起脱敏。
- 腹部频率与五日主计划不同 → 在可见计划说明中保留可选频率及后续加组建议，不改变主训练循环。
