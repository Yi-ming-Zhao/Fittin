# Android 实机运动验收（尚未执行）

这份表是验收步骤，不是测试通过记录。模拟坐标、浏览器截图和构建成功
均不能替代本表。测试时不把精确路线、住址或账户凭证放进 Git 仓库。

## 测试前

- 记录设备型号、Android 版本、应用版本、APK 签名及文件校验值。
- 从正式签名的上一版覆盖安装候选版，核对登录、计划、历史和配置保留。
- 选择有独立已知距离的路线，记录距离来源；不能把应用自己的计算值
  或同一条模拟路线作为真值。无需在报告公开路线起终点。
- 核实权限说明、定位前台通知、暂停/结束停止采集、地图隐私同意。
- 在默认电池策略下测试；如设备必须手动允许后台运行，报告该限制，
  不能只在放宽全部系统限制后声称默认后台记录可靠。

## 连续锁屏场景

1. 从 Fittin 主动开始一条户外运动，确认收到定位与前台通知。
2. 锁屏连续记录至少 60 分钟。运动中不操作手机；需要操作时先停在安全位置。
3. 结束后核对运动时长、总时长、距离、分段和定位中断标记。
4. 记录已知距离、测量距离和相对误差。解释异常区段，不能删除异常后
   只报告最好的部分。地图加载失败不得停止计时和路线保存。
5. 核对该路线没有进入普通云同步、Agent 工具结果或诊断日志。

## 故障与恢复场景（独立进行）

- 手动暂停后发生位移，再继续：暂停时长独立，暂停位移不累计。
- 飞行模式/断网：计时和本机定位继续；地图允许不可用。
- 定位失联/漂移：显示信号状态，不桥接缺失区间，不生成虚假配速。
- 撤回定位权限：停止采集并保留可恢复记录，提示原因。
- 系统终止进程：重开后以“已中断”恢复已保存数据，明确点击继续才采集。
- 账号切换：旧账号路线不可见，旧订阅取消，不能保存到新账号。
- 保存/重试/快速点击：同一运动至多产生一条汇总。
- 删除汇总：不把已有本机路线重新当作待保存运动。
- 导出和路线云同步分别确认；取消确认时不得发送精确路线。
